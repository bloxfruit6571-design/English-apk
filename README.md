# English Quest

> **Pembayaran terbaru:** [DANA + WhatsApp manual](PEMBAYARAN-DANA-WHATSAPP.md), diuji lokal; source belum berarti APK/layanan online sudah diperbarui.
> **Status hosting:** lihat [Laporan A–L](LAPORAN-HOSTING-PREMIUM.md) dan
> [pilihan hosting](deploy/PILIHAN-HOSTING.md). Belum ada backend HTTPS publik yang diuji.

> Berkas deployment perlu diterapkan dari commit persiapan; konfigurasi VPS tidak langsung
> kompatibel dengan Render/Railway tanpa adapter yang diuji.

English Quest adalah aplikasi belajar bahasa Inggris offline-first dalam bentuk PWA dan APK Android WebView. Pelajaran utama, artikel perpustakaan, ilustrasi, karakter, dan model Vosk tetap dibundel lokal. Saat backend tersedia, sesi akun dan jatah demo 5-soal diverifikasi server; jika backend tidak tersedia, tersedia demo lokal terbatas (bukan anti-tamper server-grade). Token Premium dan peran admin selalu memerlukan verifikasi server. Progres belajar tetap tersimpan lokal dan tidak dihapus saat akun dibuat atau Premium diaktifkan.

## Menjalankan dan memasang

- **Pratinjau PWA statis:** jalankan `python3 -m http.server 4173 --bind 0.0.0.0` di folder ini, lalu buka `http://localhost:4173`. UI dan demo lokal terbatas dapat dicoba tanpa backend; sesi demo server, login/sinkronisasi akun, dan Premium memerlukan backend dari bagian development di bawah. Untuk instalasi PWA, gunakan HTTPS atau localhost agar Service Worker aktif.
- **Android:** APK debug terbaru, [`English-Quest-1.7.1-debug.apk`](./English-Quest-1.7.1-debug.apk), package `com.englishquest.app.debug`, version code 13, minimum API 23, target API 35, ukuran 85,079,299 byte (sekitar 81 MiB). Ditandatangani dengan debug key lokal yang sama seperti APK 1.7.0. SHA-256: `05e066414f831de225087d47bf00f3892810cc70b3343c5a228cfeda914bbd86`. APK untuk sideload/debug, bukan rilis Play Store. API production belum dikonfigurasi; demo lokal terbatas tetap tersedia, sedangkan sinkronisasi akun dan Premium menunggu backend HTTPS.
- **Android source:** proyek `english-quest-android/` versi 1.7.1 (package `com.englishquest.app`, version code 13, minimum API 23, target API 35). Untuk build ulang gunakan instruksi di bawah.
- **Build Android:** dari `english-quest-android/`, jalankan `bash ./gradlew --no-daemon :app:assembleDebug` dengan JDK 17+ dan Android SDK API 35. Android Gradle Plugin menyiapkan Build Tools yang diperlukan. Build memverifikasi SHA-256 model Vosk sebelum memasukkannya ke APK.

## Akun, demo, token Premium, dan admin (source 1.7.1)

- Halaman sambutan menyediakan **Coba Demo Gratis**, **Aktivasi Premium**, dan **Masuk / Buat Akun**. Demo tamu tidak memerlukan token, email, atau kata sandi. Jika server dikonfigurasi, aplikasi membuat sesi demo tamu dan menghitung kuota di server; jika API belum dikonfigurasi atau tidak terjangkau, aplikasi membuka demo lokal terbatas dengan pesan status server berbahasa Indonesia. Login/pendaftaran tersedia untuk menyimpan kuota di akun. Kata sandi akun minimal **6 karakter** (akun admin yang dibuat offline tetap 12 karakter) diproses dengan PBKDF2-HMAC-SHA-256 + salt unik; formulir pendaftaran menyediakan tombol lihat/sembunyikan kata sandi dan memvalidasi email serta panjang kata sandi di klien sebelum dikirim ke server. Origin API untuk APK diberikan lewat bridge Android (`EnglishQuestAndroid.getApiBaseUrl()`) dari `BuildConfig.EQ_API_BASE_URL`, bukan dari origin aset WebView. API menerbitkan session bearer acak 256-bit, menyimpan hash sesi, kedaluwarsa 30 hari, dan mencabut sesi saat logout.
- **Demo 5 soal unik** memakai satu misi Easy lengkap yang dipilih secara eksplisit (Greetings & Introductions, 5 soal). Perubahan dari 10 ke 5 soal ini adalah aturan bisnis Premium terbaru: misi Easy kedua (Alphabet & Spelling) kini termasuk materi Premium. Soal dihitung saat jawaban dikirim—benar maupun salah—bukan saat dibuka. ID soal unik, submit ganda dicegah, dan soal yang sudah dipakai tidak dapat diulang. Server menyimpan `(user, question_id)` unik dan HMAC jawaban; retry jaringan dengan jawaban sama idempoten, perubahan jawaban ditolak. ID dari ledger lokal yang belum tersinkron dapat diimpor secara idempoten ke akun dan hanya mengurangi kuota, tidak membuat jawaban yang bisa diputar ulang. Kuota server melekat pada akun dan tetap berlaku setelah instal ulang. Demo tamu dibatasi 20 sesi baru per alamat IP per hari; kuota akun tetap per akun, bukan verifikasi identitas per orang.
- Fallback lokal menyimpan 5 ID unik melalui localStorage dan jalur cadangan Android; reload profil diuji di Node VM, tetapi persistensi restart pada perangkat nyata belum diverifikasi. Ini tetap **bukan** anti-tamper server-grade—pengguna yang menghapus atau memanipulasi data aplikasi dapat mereset ledger lokal. Fallback ini hanya membuka demo Easy yang diizinkan; tidak memberi Premium. Saat kuota habis, beranda, statistik/progres, pengaturan, info/aktivasi Premium, dan perpustakaan informasi tetap dapat dibuka, tetapi soal baru dan konten Premium dikunci saat navigasi maupun submit. Informasi server lokal/offline/unconfigured ditampilkan dengan jelas.
- Demo mengunci pelajaran/ujian, Medium/Hard/Mode Bule, misi Easy kedua dan misi lain, mini games, listening, Story Mode, dan soal interaktif perpustakaan. Hak Premium ditentukan hanya oleh status terverifikasi server, bukan XP atau flag lokal. Klaim token memerlukan akun permanen (akun tamu tidak dapat mengklaim token yang tak dapat dipulihkan); akun reguler dapat mengaktifkan Premium. Jika server gagal diverifikasi, fitur Premium fail-closed sementara progres lokal tetap disimpan.
- `backend/server.py` menyediakan API JSON dan static PWA/admin hanya dengan Python standard library + SQLite. Token berformat `EQP-` + 48 digit heksadesimal acak (192-bit), disimpan sebagai HMAC-SHA-256 dengan `EQ_TOKEN_PEPPER`; claim menggunakan transaksi `BEGIN IMMEDIATE` dan unique row agar hanya satu akun yang menang dalam claim bersamaan. Status yang dikembalikan API/admin: `available`, `used`, `revoked`, dan `expired` mendukung klaim, kedaluwarsa, dan pencabutan. Token plaintext hanya dikirim satu kali saat pembuatan; daftar admin tidak pernah mengembalikan plaintext maupun hash. Rate limit dipasang pada pendaftaran, login, claim, sinkronisasi, pemakaian demo, dan pembuatan sesi tamu. Access log dinonaktifkan untuk mencegah kode/kredensial masuk log.
- **Pembayaran terbaru: DANA manual Rp5.000 sekali bayar, permanen, tanpa langganan.** Pembeli menyalin nomor DANA, mengirim screenshot lewat WhatsApp, dan menunggu pemeriksaan uang masuk oleh admin. Screenshot bukan bukti final. Admin mencatat pembayaran untuk email akun pembeli lalu menerbitkan satu token; tidak ada tombol checkout atau pesanan yang perlu dibuat pembeli. Pembeli memasukkan token untuk aktivasi; tombol pembayaran/screenshot tidak pernah memberi Premium.
- Dashboard `/admin` menyediakan daftar/pencarian/filter pesanan, verifikasi/tolak, penerbitan sekali, status token/aktivasi dan audit. Pembuatan token generik dihapus dari UI dan ditolak oleh API produksi. Semua tindakan memeriksa admin di backend. Buat akun admin melalui `backend/manage.py create-admin`; kata sandi diminta secara interaktif, tidak ditaruh dalam APK.
- **Konfigurasi manual:** `EQ_DANA_MANUAL_NUMBER`, `EQ_DANA_MANUAL_NAME`, dan `EQ_WHATSAPP_ADMIN_NUMBER`, semuanya sengaja kosong. Tanpa konfigurasi valid, pembelian belum tersedia. Harga tetap ditentukan server, bukan body dari klien. Lihat [panduan DANA–WhatsApp](PEMBAYARAN-DANA-WHATSAPP.md) untuk operasi admin, endpoint, migrasi dan batas kode sekali tampil.
- Jalur otomatis lama (checkout/webhook/claim) tidak aktif di produksi. Kodenya hanya dipertahankan untuk kompatibilitas data lama dan tes loopback yang secara eksplisit mengaktifkan insecure development. Tidak perlu merchant credential/webhook untuk alur manual. Jangan isi `EQ_PAYMENT_PROVIDER` pada konfigurasi produksi manual.
- **Belum siap digunakan online:** penerima, backend HTTPS publik, disk persisten/backup, jalur admin privat, kanal penyerahan kode, kebijakan kehilangan kode/refund, build APK dan uji HP nyata belum diselesaikan. Tidak ada transaksi sungguhan atau deployment pada pekerjaan lokal ini.
- **Jalankan backend development lokal** (data/pepper contoh khusus dev; jangan gunakan nilai ini di production):

  ```sh
  export EQ_TOKEN_PEPPER="$(python3 -c 'import secrets; print(secrets.token_urlsafe(48))')"
  export EQ_DB_PATH="$PWD/backend/data/development.sqlite3"
  export EQ_ALLOW_INSECURE_DEV=1 EQ_HOST=127.0.0.1 EQ_PORT=8088
  # Sekali saja, buat admin menggunakan DB dan pepper yang sama:
  python3 backend/manage.py create-admin --email admin@example.com
  # Lalu jalankan API:
  python3 backend/server.py
  ```

  Buka `http://127.0.0.1:8088` untuk PWA + API satu origin. **Simpan pepper development yang sama** bila server perlu dimulai ulang; mengganti pepper membuat token yang belum diklaim tak dapat dicari lagi. Saat admin sudah dibuat, lewati perintah `create-admin` pada restart berikutnya. Kata sandi admin diminta secara interaktif. Contoh ini hanya menerima HTTP loopback untuk development.
- **Production belum dikonfigurasi atau dideploy.** Sebelum melayani pengguna, sediakan domain/hosting, HTTPS, secret pepper random di secret manager, direktori SQLite persisten + backup, provisioning admin, firewall, reverse proxy TLS, monitoring, proses restart, rotasi/backup pepper, email verification/password recovery dan kebijakan anti-abuse. Jalankan server di loopback di belakang reverse proxy tepercaya dengan `EQ_TRUST_PROXY=1`; proxy harus menjadi satu-satunya jalur jaringan ke proses API dan mengatur (bukan sekadar meneruskan input klien) `X-Forwarded-Proto`/`X-Forwarded-For`. Set `EQ_ALLOWED_ORIGINS` ke origin PWA dan `https://appassets.androidplatform.net` (untuk APK lintas-origin), lalu jangan expose port backend ke internet. Alternatif direct TLS memakai `EQ_TLS_CERT_FILE`/`EQ_TLS_KEY_FILE`. Satu SQLite/API instance ditujukan untuk integrasi awal, bukan deployment multi-node berskala besar.
- **Konfigurasi APK:** `EQ_API_BASE_URL` adalah origin publik HTTPS (bukan secret), dapat diberikan ke Gradle sebagai `-PEQ_API_BASE_URL=https://app.example.com` atau environment variable. Nilai APK 1.7.1 ini sengaja kosong karena tidak ada origin production yang tersedia: demo lokal tetap bisa dibuka, sementara login/sinkronisasi akun/token Premium menunggu server online yang terverifikasi. PWA memakai API origin yang sama; bila dipisah, set `window.EQ_API_BASE='https://api.example.com'` pada `index.html` sebelum `access-client.js` dan whitelist origin PWA di `EQ_ALLOWED_ORIGINS`. Jangan memasukkan pepper, kata sandi, token, atau kunci layanan ke `BuildConfig`.
- Test lokal source: `python3 -m unittest discover -s tests -v` menjalankan 65 tes (17 API/service termasuk kontrak pendaftaran 6 karakter, 14 failure path, 34 pembayaran Premium: batas demo 5 soal, harga Rp5.000, verifikasi tanda tangan webhook HMAC dan RSA-SNAP, dedupe notifikasi, penerbitan token otomatis, penebusan sekali pakai, dan akses Premium permanen). `node tests/client_gates.test.js` menguji 11 kelompok akses termasuk local fallback, kuota 5/restart, guest start/sync, duplicate submit, alur pembelian Premium, premium fail-closed, progress retention, dan admin role; semua 43 route renderer juga di-smoke-test dalam Node VM. `node tests/client_registration.test.js` menguji 12 kelompok alur pendaftaran (sukses, kata sandi <6 ditolak, email tidak valid, akun sudah ada, server tidak tersedia, timeout, respons server tidak valid, tombol lihat/sembunyikan kata sandi, login setelah daftar) termasuk uji end-to-end terhadap `backend/server.py` asli dan pemeriksaan bahwa kata sandi tidak pernah tersimpan sebagai teks biasa. Ini bukan pengujian deployment/customer account.

## Fitur

- **30 pelajaran dalam 6 level** dengan penjelasan Indonesia, kosakata, panduan pelafalan, contoh, cerita, dialog, latihan, kuis, dan pembahasan. Materi lama dan jalur progres dipertahankan.
- **Perpustakaan gratis dan offline:** 17 artikel berbahasa Indonesia tentang grammar, kosakata, speaking, pronunciation, reading, dan writing. Tiap artikel memuat tujuan belajar, materi bertahap, contoh dwibahasa, kesalahan umum, poin ringkas, dan cek pemahaman. Ada kategori, pencarian, bookmark, progres baca, dan audio contoh; tidak memerlukan koin atau internet, tetapi akses aplikasi tetap melalui akun Demo/Premium.
- **Lima karakter lokal:** Aki, Rina, Bimo, Naya, dan Suki. Potret original WebP ringan digunakan langsung oleh UI; dialog dan respons karakter menyesuaikan adegan. Suki aktif sebagai rival komedi dan tantangan checkpoint yang boleh dilewati.
- **Character Creator:** ubah nama, model, rambut, mata, aksesori, pakaian, warna, sepatu, dan ekspresi. Preview langsung, simpan/edit/gunakan/reset, serta dukungan karakter aktif di profil, cerita, dan layar kemenangan.
- **Story Mode dan percakapan:** adegan responsif untuk layar ponsel, pilihan dengan konsekuensi dialog, terjemahan, kosakata, kontrol suara, serta navigasi yang tidak tertutup menu bawah.
- **Latihan mikrofon offline di Android:** menggunakan model English Vosk yang dibundel di APK, bukan SpeechRecognizer Android atau paket bahasa terpisah. PCM direkam lewat `AudioRecord` secara lokal; sumber `VOICE_RECOGNITION` dicoba lebih dahulu dan `MIC` menjadi fallback bila inisialisasi sumber pertama gagal. Model diekstrak sekali ke penyimpanan privat (sekitar 71 MB) dan memerlukan RAM yang cukup. Aplikasi tidak mengirim audio ke internet dalam mode offline.
- **Online fallback bersifat opt-in:** mati secara default. Tombol “Coba online” meminta izin untuk satu percobaan; fallback otomatis hanya berjalan setelah diaktifkan di Pengaturan. Audio dapat diproses layanan pengenal suara Android melalui internet setelah persetujuan. Tidak ada fallback online diam-diam.
- **TTS English:** menggunakan voice yang tersedia di perangkat. Suara laki-laki/perempuan dicocokkan otomatis dengan gender karakter bila engine mengungkapkan voice yang sesuai; pilihan gender manual tetap tersedia. Jika voice yang cocok tidak ada, UI memberi tahu dan memakai voice English bawaan, jika tersedia.
- **Suki Showdown** mencakup kosakata, grammar, listening, dan percakapan. Tantangan mengikuti mode belajar, membutuhkan setidaknya 3/4 jawaban benar, dan boleh dilewati tanpa kehilangan progres/XP.
- **Listening Detective** menyembunyikan kalimat dan arti sampai jawaban dipilih. Petunjuk dibuka hanya bila diminta; setelah menjawab, materi dan panduan baca ditampilkan.
- **Latihan dan game lain:** Picture Quiz dengan ilustrasi lokal, Word Hunter, Grammar Puzzle, Vocabulary Match, Speed Quiz, listening, dialog, ujian level, kamus pencarian/bookmark, statistik, XP, dan ekspor progres.
- **Audio dan SFX:** musik latar dibuat lokal oleh Web Audio, efek sentuh tombol dapat dinyalakan/dimatikan, dan ada tombol uji SFX. TTS menyediakan kecepatan, suara pelan, jeda/lanjut/henti, dan respons error.
- **Progres dan aksesibilitas:** mode Easy/Medium/Hard/Mode Bule, tema gelap, ukuran teks, progres dan kuis tersimpan, dukungan cadangan SharedPreferences Android serta localStorage, dan ekspor JSON. Materi penting tidak dikunci koin. Streak bertambah maksimal sekali per tanggal lokal setelah misi baru lulus pertama kali atau satu level penuh—bukan karena membuka aplikasi atau mengulang aktivitas.

- **Sistem misi global (source 1.6.0):** Easy memiliki 25 misi, Medium 25, Hard 29, dan Mode Bule 10; setiap misi berisi lima soal buatan khusus, deskripsi, status, dan hadiah tetap 20 XP. Easy terbuka di Global Level 0, Medium di Level 5 / 500 XP, Hard di Level 10 / 1.000 XP, dan Mode Bule di Level 15 / 1.500 XP setelah Hard Final Exam lulus. Home menampilkan Level/XP, sisa XP ke level berikutnya, status buka tiap mode, dan tombol progres grinding. Semua soal wajib dijawab; skor lulus 80%. Misi sebelumnya tidak perlu diulang, XP pertama lulus dibayar sekali saja, latihan ulang tidak membayar lagi, dan percobaan gagal dapat diulang tanpa kehilangan progres. Level dihitung dari total XP (100 XP per level), tanpa syarat streak; beralih mode tidak mereset progres. Mode Bule memakai konten/UI bahasa Inggris tingkat lanjut dengan terjemahan Indonesia opsional yang tersembunyi secara default. Suki tetap menjadi rival edukatif kontekstual.

## Privasi dan batasan

- APK adalah wrapper WebView dengan aset aplikasi dibundel lokal; ini bukan aplikasi native terpisah. Ringkasan Wikipedia dan tautan sumber opsional memerlukan koneksi. Progres belajar PWA dan APK disimpan terpisah secara lokal; identitas akun, ledger demo, dan entitlement Premium disimpan server.
- Izin mikrofon diminta saat pengguna memulai latihan. Pengenalan offline berjalan di perangkat dengan model terbundel. Hasil ASR tetap bergantung pada performa/perangkat; halaman web preview tidak memiliki bridge mikrofon Android.
- Online hanya dapat digunakan setelah izin eksplisit di aplikasi. Penyedia layanan suara Android dapat memproses audio melalui internet setelah mode itu disetujui.
- TTS memerlukan engine dan voice English yang tersedia di perangkat; suara tidak dibundel sebagai rekaman. Gender voice yang tidak tersedia akan memakai voice default dan ditandai oleh aplikasi.
- **Pengenalan suara dan TTS belum diuji pada HP atau emulator dalam sesi QA ini.** Build berhasil dan pemeriksaan source/asset lulus, tetapi hal itu bukan bukti bahwa input mikrofon atau engine suara berfungsi pada setiap perangkat.

## Perbaikan pendaftaran akun — 15 Oktober 2026 (branch `audit-baseline-1.7.1`)

- **Akar masalah #1 — APK tidak pernah bisa mendaftar.** `access-client.js` meminta origin API ke bridge native (`window.EnglishQuestAndroid.getApiBaseUrl()`), tetapi `MainActivity` tidak pernah menyediakan metode itu. Di dalam APK, origin halaman adalah `https://appassets.androidplatform.net` yang memang ditolak sebagai origin API, sehingga `isConfigured()` selalu `false`: tombol "Buat akun & lanjut" `disabled` dan halaman menampilkan "Server akun belum dikonfigurasi…". Perbaikan: metode bridge baru `getApiBaseUrl()` (mengembalikan `BuildConfig.EQ_API_BASE_URL`) dan `isHttpDevAllowed()` (hanya `true` untuk debug build dengan `-PEQ_ALLOW_HTTP_DEV=1`) di `MainActivity`, field `BuildConfig.EQ_ALLOW_HTTP_DEV` di `app/build.gradle`, serta `index.html` yang membaca flag tersebut dari bridge.
- **Akar masalah #2 — kebijakan kata sandi tidak sesuai kontrak.** Klien dan server sama-sama menuntut minimal 12 karakter, padahal kontrak produk adalah minimal 6 karakter; setiap pengguna yang memilih kata sandi 6–11 karakter ditolak `400 WEAK_PASSWORD` ("Kata sandi harus 12–256 karakter."). Perbaikan: `PASSWORD_MIN_LENGTH = 6` dan `PASSWORD_MAX_LENGTH = 256` di `backend/server.py`, nilai yang sama dimirror di klien, pesan kesalahan menyebut batas sebenarnya, dan akun admin yang dibuat offline tetap 12 karakter.
