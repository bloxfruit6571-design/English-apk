✨ Operations desk

Dashboard token Premium

Buat kode akses sekali pakai, pantau status claim, dan cabut akses bila diperlukan. Kode plaintext hanya ditampilkan pada respons pembuatan dan tidak dapat dibuka kembali.

🎟️ Buat token

Buat satu kode atau batch hingga 500. Token disimpan di server sebagai HMAC-SHA-256, bukan plaintext.

⚠️ Salin sekarang — plaintext hanya muncul sekali.

💳 Pesanan pembayaran Premium

Pesanan Rp5.000 sekali bayar. Tabel ini hanya membaca data server: token diterbitkan otomatis setelah pembayaran terverifikasi, dan status review menandai pembayaran yang perlu ditinjau manual (nominal tidak cocok atau dibayar setelah pesanan kedaluwarsa).
